# Expense Tracker Management System

## Description
The Expense Tracker Management System is a console-based Java application that helps users manage their daily expenses.

## Technologies Used
- Core Java
- JDBC
- MySQL
- VS Code

## Features
1. Add Expense
2. View All Expenses
3. Search Expense by Category
4. Update Expense
5. Delete Expense
6. Calculate Total Expenses
7. Calculate Monthly Expenses
8. Exit

## Database
MySQL is used to store expense records. The `database.sql` file contains the database and table creation queries.

## How to Run
1. Install Java and MySQL.
2. Run `database.sql` in MySQL.
3. Download MySQL Connector/J and place its JAR file in the `lib` folder.
4. Set the `DB_PASSWORD` environment variable to your local MySQL password.
5. Compile and run the Java application.

## Learning Outcomes
This project demonstrates Java programming, JDBC connectivity, SQL queries, CRUD operations, and expense management.
